*dap-memview.txt*  Memory viewer (hex dump) for nvim-dap

==============================================================================
INTRODUCTION                                                    *dap-memview*

dap-memview shows a live hex dump of debuggee memory using the DAP
`readMemory` request. It refreshes on every stop and highlights bytes that
changed since the previous stop.

Requires Neovim >= 0.10, nvim-dap, and an adapter that advertises
`supportsReadMemoryRequest` (codelldb, lldb-dap, cppdbg, gdb -i dap).

==============================================================================
COMMANDS                                               *dap-memview-commands*

:DapMemView [{expr}]                                            *:DapMemView*
    Open the memory view for {expr} (e.g. `&buf`, `argv`, `0x7ffe...`).
    Without an argument, uses the <cexpr> under the cursor. Requires an
    active, stopped debug session.

:DapMemViewClose                                           *:DapMemViewClose*
    Close the memory view window.

==============================================================================
MAPPINGS (buffer-local)                                *dap-memview-mappings*

    r      refresh
    ]      page forward
    [      page backward
    <CR>   follow the pointer under the cursor (8 bytes, little-endian)
    <BS>   back to the location before the last follow/goto
    g      prompt for a new expression
    q      close

==============================================================================
SETUP                                                     *dap-memview-setup*

>lua
    require('dap-memview').setup {
      bytes_per_line = 16,
      count = 256,
      auto_refresh = true,
      window = { position = 'botright', height = 18 },
      keymaps = {            -- buffer-local; set one to false to disable it
        refresh = 'r',
        close = 'q',
        page_next = ']',
        page_prev = '[',
        goto_expr = 'g',
        follow = '<CR>',
        back = '<BS>',
      },
    }
<

Highlight groups: *DapMemviewChanged* (default: DiffText),
*DapMemviewAddr* (default: LineNr), *DapMemviewHeader* (default: Title).
